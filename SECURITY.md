# Security policy

This repository is a public starter. Treat every tracked file and every Git
commit as public forever.

## Never commit

- Client, customer, employee, or contact data
- Codex sessions, memories, caches, databases, or authentication state
- API tokens, passwords, private keys, cookies, environment files, or SSH keys
- Private repository URLs, internal hostnames, deployment IDs, or access rules
- CRM exports, outreach lists, invoices, files, screenshots, or support logs
- Machine-specific paths or configuration containing a real person's identity

Keep operational data in a new **private** working repository created from this
starter. Keep secrets in each PC's local environment or an approved secret
manager. Never place them in dashboard JSON or browser code.

## Reporting a vulnerability

Do not open a public issue containing sensitive evidence. Contact the repository
owner privately through their GitHub profile and provide only the minimum
information needed to coordinate a secure report.
